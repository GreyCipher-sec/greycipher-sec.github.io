This blog existed in a few different forms.

The idea was always roughly the same: a place to write down what I'm learning, what I'm building and the things I end up spending far too much time trying to understand.

This time, I wanted to approach it a little differently.

I don't want this to become a conventional tech blog where every post has to be a polished tutorial or an impressive project. There is value in those things, but they aren't a very good representation of how I actually learn.

A lot of learning happens in the middle.

Reading something for the first time. Trying it. Getting it wrong. Following a strange result. Building a small tool just to answer one question. Taking something apart because I want to know what is actually happening underneath,

Those are the things I want to keep here.

## Why Zola?

The previous version of the blog was build with Hugo. It worked well enough, but over time I found myself wanting something simpler and closer to the way I actually work.

I ended up moving to **Zola**.

The choice wasn't about finding the most powerful static site generator. Quite the opposite. I wanted something small, fast and predictable.

No database. No runtime application. No complicated stack sitting between a text file and a webpage.

Just a collection of files that can be understood, versioned, moved and rebuilt.

## NOIR

The new site also comes with a new theme: **NOIR**.

I wanted the interface to feel more like a technical notebook or an archive than a traditional blog. Something quite and functional, with enough character to make the site feel like its own place without getting in the way of content.

That eventually became a theme of its own, so I decided to keep it separate from the blog and make it available as a project.

It is still evolving, just like the rest of this site.

## What comes next

I don't have a strict publishing schedule or a carefully planned editorial calendar.

There are things I want to learn, things I want to build and plenty of questions I haven't answered yet. Some of those will probably turn into posts. Others will disappear into a folder somewhere and never be seen again.

That's okay.

The point of bringing this blog back isn't to create a finished publication.

It's to have a place where the work can accumulate.

A place for notes that would otherwise disappear, projects that deserve more than a Git repository and questions that are worth following a little further.

So, this is the new beginning.

Let's see where it goes.
