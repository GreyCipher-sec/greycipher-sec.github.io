# GreyCipher

Personal technical blog and research archive.

This repository contains the source of [GreyCipher](https://www.greycipher.dev/), a personal archive for technical writing, research, projects, notes, CTF write-ups and wargame logs.

The site is built with [Zola](https://www.getzola.org/) and uses [NOIR](https://github.com/GreyCipher-sec/NOIR) as its theme.

## Content

The site is organized into several sections:

* **Posts** - long-form technical articles and research
* **Projects** - software, hardware, and engineering projects
* **Notes** - shorter technical notes and references
* **CTF** - CTF write-ups and security research
* **Wargames** - notes and logs from wargame platforms
* **About** - information about the author and the archive

## Development

Requirements:

* [Zola](https://www.getzola.org/)

Run the development server:

```bash
zola serve
```

Build the site:

```bash
zola build
```

## Theme

The site uses **NOIR**, a minimalist Zola theme developed for technical archives, research notebooks and engineering blogs.

NOIR is intentionally built around:

- no JavaScript
- no tracking
- no external requests
- self-hosted assets
- static HTML and CSS
- long-form readability
- minimal visual noise

See the [NOIR repository](https://github.com/GreyCipher-sec/NOIR) for the theme itself.

## Philosophy

GreyCipher is intended to function less as a conventional personal blog and more as a persistent technical archive.

The goal is to document things worth keeping: systems, experiments, implementations, investigations, projects and the reasoning behind them.

> Build it. Understand it. Document it.
